# Artifact fidelity

Use these rules for restoration, copy/export/transplant work, exact-format deliverables, native office/media artifacts, interactive outputs, or anything validated by a renderer/consumer.

- Bind the exact source object and requested destination surface. Preserve requested paths, roots, names, metadata, order, contents, and format semantics that are part of the contract.
- When the task forbids copying or asks for a generator, model, program, renderer, or reproducer instead of a duplicate artifact, infer reusable rules and parameters. Do not smuggle bulk source or output bytes into the result as encoded data.
- For parser, format, protocol, and round-trip work, preserve grammar roles consistently: sentinels, delimiters, comments, case rules, missing values, command variants, escaping, and read/write symmetry where the format requires them.
- Requested native features are deliverables. Tables, formulas, comments, charts, pivots, fields, layers, labels, legends, controls, links, permissions, services, and persistent state must exist as real medium/API features, not visual approximations or flattened decoration.
- Keep data, labels, decorative elements, semantic layers, encoded channels, and interactions distinct in visual, media, interactive, and fixed-format work.
- Build a complete rough artifact after one bounded structural read when feasible, then verify it through the real renderer or consumer. Repair the failed public axis rather than repeatedly fitting unrelated variants.
- For exact-byte or exact-text surfaces, define the submitted surface before drafting. Check material constraints such as required/forbidden literals, case, punctuation, wrappers, first/last bytes, order, count, format, and length over that exact surface.
- Add fences, headings, preambles, trailers, or wrappers only when the requested output surface permits or requires them.
- For lower-bound-only length requirements, leave safe surplus when useful. For maximum, exact-size, or strict-concision requirements, count the final submitted surface before delivery.
